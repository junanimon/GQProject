# 01. 루루 — 「자칭 대마법사」

> **한 줄 컨셉**: 폭발 마법 하나로 세상을 이기려는 14살. 허세는 가난을 가리는 망토다.
> 키워드: 허세 · 츤데레 · 폭발 · 고아원 · 조급함 · "대마법사 루루님"
> 플레이어 감정 목표: 처음엔 귀여운 사고뭉치 → "이 애는 내가 지켜야 해"

## 2. 외관

**전체 인상**: 몸보다 큰 마녀 모자와 로브를 걸친 작은 아이. 걸을 때마다 모자가 흔들린다. 옷은 낡았지만 손질은 꼼꼼하다.

- **머리**: 분홍빛 트윈테일, 어깨까지 오는 길이. 앞머리는 스스로 잘라서 들쭉날쭉. 폭발 후엔 끝이 살짝 그을려 있다
- **눈**: 크고 동그란 보라색 눈. 자신만만할 땐 반쯤 감고 입꼬리를 올림
- **얼굴**: 볼이 통통하고 주근깨가 살짝. 코 끝에 늘 그을음 자국
- **복장**
  - 보라색 마녀 모자 (금색 띠). 원장 할머니가 옛 커튼으로 만들어 준 것 — 루루의 보물
  - 소매가 긴 보라색 로브, 몸에 비해 큼 (고아원 후원 옷). 소매를 두 번 접어 입음
  - 허리에 금색 끈, 동전 주머니가 3개 (하나는 '약값', 하나는 '학비', 하나는 '빵값')
  - 낡은 갈색 부츠, 한쪽 끈이 다른 색
- **소품**: 끝이 탄 나무 지팡이 (별 모양 장식은 직접 깎은 것). 목에 작은 호루라기 (고아원 아이들이 부르면 달려가려고)
- **컬러 팔레트**: 머리 `#FF8CB8` · 눈 `#9959D9` · 로브 `#6B479E` · 포인트 `#F2C74D` · 그을음 `#3A2E2E`
- **표정 세트 (스탠딩 발주용)**
  1. 기본 — 턱을 들고 한쪽 입꼬리를 올린 자신만만한 얼굴
  2. 기쁨 — 두 팔 벌려 "봤지?!" (지팡이 번쩍)
  3. 화남 — 볼 부풀리고 발 구르기
  4. 당황 — 모자로 얼굴 가리기, 귀까지 빨개짐
  5. 슬픔 — 모자 챙을 꾹 눌러 눈을 숨김 (울지 않은 척)
  6. 특수 — 폭발 직후, 얼굴 그을음 + 머리 뻗침
- **일러스트 메모**: 실루엣만으로도 '모자 + 트윈테일'로 식별되게. 옷의 '큰 사이즈감'이 중요(소매로 손이 반쯤 가려짐)
- **현재 임시 그림과 차이**: 임시 그림은 로브가 길고 모자가 작음. 실제로는 모자를 더 크게, 주머니 3개 표현 필요

## 3. 성격

| 겉 | 속 |
|---|---|
| 허세, 자신만만, 시끄러움 | 불안, 책임감, 조급함 |
| "대마법사 루루님" 3인칭 | 사실 자기가 대단하지 않다는 걸 누구보다 앎 |
| 큰 보수만 노리는 돈벌레 | 돈은 전부 고아원과 할머니 약값으로 감 |

- **장점**: 포기하지 않음. 아이들 앞에선 절대 약한 모습 안 보임. 약속은 무조건 지킴
- **단점**: 자기 한계를 인정 못 함 → 무리한 의뢰를 고름(게임 내 '욕심' 0.6의 근거). 칭찬받으면 폭주
- **버릇**
  - 말끝마다 "후후후"
  - 돈 얘기가 나오면 손가락으로 계산함
  - 거짓말할 때 모자를 고쳐 씀 (허위 보고 연출에 활용 가능)
- **말투 규칙**: 반말. 자기를 3인칭 "루루님"으로 부르다가, 진심일 때만 "나"로 바뀜 (호감도 70 이벤트의 전환점)
- **대사 예시**
  - 인사: "후후후, 대마법사 루루님이 오늘도 강림하셨다!" [구현됨]
  - 규정에 걸림: "으, 으으… 등급 같은 건 숫자일 뿐인데…" [구현됨]
  - 실패: "마, 마력이 좀 부족했을 뿐이야! 절대 진 거 아니야!" [구현됨]
  - (추가) 칭찬받았을 때: "다, 당연하지! …근데 한 번만 더 말해 봐."
  - (추가) 할머니 얘기가 나오면: "…할머니 얘긴 하지 마. 아니, 해도 되는데. 좋은 얘기만."

## 4. 배경 이야기

1. **0세** — 눈 오는 밤, 들꽃 고아원 문 앞 바구니에서 발견. 바구니엔 이름 쪽지 한 장 '루루'.
2. **7세** — 고아원 난로에 불을 붙이려다 처음으로 마력 폭주. 부엌 벽이 날아감. 원장 할머니가 혼내지 않고 "재능이구나" 하며 안아 줌 → 루루 인생의 원점
3. **12세** — 할머니가 모아 둔 돈으로 왕도 마법 학원에 입학. 기초 이론은 꼴찌, 폭발 실습만 1등
4. **12세 겨울** — 둘째 학기 학비를 못 내 퇴학. 친구들에게는 "학원이 나를 감당 못 해서 나왔다"고 말함
5. **13세** — 고아원에 돌아옴. 할머니가 기침을 시작. 약값이 고아원 한 달 식비만큼 든다는 걸 앎
6. **14세 (현재)** — 모험가 등록. 동급이지만 한 방에 큰돈을 벌 수 있는 의뢰만 노림. 번 돈은 주머니 셋에 나눠 담음

**비밀 [구현됨]**: 약값 / 퇴학 / 폭발밖에 못 씀
**비밀 [추가 제안]**: 루루를 버린 부모는 사실 마법사 가문 — 폭발 마법 체질은 유전. 5주차 이후 후속작/DLC 떡밥으로 보류

## 5. 게임 내 역할

- **방문 패턴** [구현됨]: 욕심 0.6 → 자기보다 한 단계 높은 의뢰를 자주 들고 옴. 위조 성향 0.15 → 위조 검사가 열린 뒤 드물게 위조 카드도 시도 (본인은 "빌린 거야"라고 함)
- **플레이어가 배우는 것**: "귀여워도 규정은 규정" — 첫 거절 대상이 되기 쉬운 캐릭터
- **호감도 반응**: 적절한 배정에 크게 기뻐함(깡총), 거절엔 발 구르기. 실제 판정에선 무리한 의뢰를 막아 준 게 결국 호감도에 이득
- **습격**: 호감도 70↑이면 "대마법사 등판이다!" 하며 달려옴. [추가 제안] 습격 연출에서 폭발로 방책 앞을 날려 버리는 전용 문장

## 8. 서사 아크 & 분기

- **아크**: 허세로 버티는 아이 → 약함을 인정 → 폭발만이 아닌 '다른 마법'을 배움 → 제어된 한 방으로 진짜 대마법사의 문턱에
- **사망 가능성**: 낮음 (아이 캐릭터의 사망은 톤 조절 필요). 대신 **3주차 무리한 의뢰 → 중상** 분기 추천: 플레이어가 욕심 의뢰를 계속 승인하면 루루가 크게 다쳐 1주일 출근 불가
- **엔딩 기여**: 호감도 85 + 4주차 이벤트 완료 시 5주차 습격 판정에 '폭발 지원' 보너스
- **떡밥**: 루루의 부모(마법사 가문) — 본편에선 풀지 않음
