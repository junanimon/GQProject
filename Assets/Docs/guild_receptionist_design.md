# 모험가 길드 접수원 게임 — 기획 요약

> 상태 표기: **[확정]** 논의로 결정됨 · **[제안]** 방향만 잡힘, 최종 결정 전 · **[미정]** 추후 논의

---

## 0. 개요

- **플랫폼/엔진** [확정]: PC(Steam), Unity **Universal 2D** 템플릿(URP 2D)
- **장르**: 판타지 서류 검수·운영 시뮬레이션
- **플레이어**: 모험가 길드의 신입 접수원
- **배경**: 시작 마을의 작은 길드 (동·은 등급이 대부분)
- **톤**: 코노스바 같은 한가로움과 코미디 → 뒤로 갈수록 사람들이 죽어가고 → 마지막에 거대한 위협
- **목표**: 정해진 기간(5주) 동안 마을을 지켜내면 엔딩
- **아트 레퍼런스**: 갈바테인(모험가 길드 사무소) 느낌
  - ⚠️ 갈바테인은 컨셉(접수원 검토)과 낮·밤 구조까지 겹침. 차별점을 전면에:
    갈바테인 = "끝난 일을 검토" / **우리 = "보내기 전에 판단"** (수주 심사, 밤 의뢰서 작성, 사망과 나비 효과, 마을 습격)

## 1. 전체 구조

- **기간** [확정]: 총 5주. 첫 회차 4~5시간 목표
- **한 주** [확정]: 평일(낮/밤 반복) + 주말 습격 이벤트
- **스토리** [확정]: 주마다 **고정 메인 이벤트** + **랜덤 이벤트**
  - 랜덤 이벤트는 조건 태그(등장 가능 주차, 특정 메인 이벤트와 배타) 부여
  - 주당 랜덤 1~2개로 제한
  - 같은 랜덤 이벤트라도 메인 스토리 진행에 따라 의미가 달라지게 [제안]
- **엔딩** [확정]: 엔딩 있는 게임. 주간 이벤트마다 다른 배드 엔딩(엔딩 도감)
- **목숨 이벤트** [확정]: 습격 실패 시 스토리 이벤트로 한 번 구제 (예: 은퇴한 길드장이 나섬)
  - 공짜가 아님: 이후 지원 중단, 자금 대량 손실 등 흔적이 남음 [제안]
  - 두 번째 실패 → 해당 주 배드 엔딩
- **재도전** [확정]: 배드 엔딩 후 **해당 주 시작부터 / 처음부터** 선택
  - 주 시작 시점 저장: 그 주에 죽은 모험가는 복귀, 이전 주에 죽은 모험가는 그대로
  - 목숨 사용 여부를 주 시작 저장에 포함할지 [미정]

### 주차별 곡선 [제안]

| 주차 | 분위기 | 해금 |
|---|---|---|
| 1주 | 한가로운 시작 마을. 황당한 의뢰. 사망 없음 | 등급, 직업, 파티 인원 |
| 2주 | 일이 늘어남. 최종 위협 떡밥 첫 등장 | 길드 인장 → 주 중반 도감·마법구 상성 |
| 3주 | **전환점**. 사망 판정 개방, 첫 죽음 | 스킬 측정, 수배서 사건 |
| 4주 | 무거워지는 마을. 원정 3일 퀘스트 | 카드 번호 |
| 5주 | 거대한 위협 | 새 규칙 없음 (배운 것 총동원) |

- 해금은 주 단위에 묶이지 않고 **주 중간 공문**으로도 가능
- 1~2주차에 네임드 잡담·개인 이벤트를 촘촘히 배치해서 3주차 첫 죽음 전에 애착 형성

## 2. 하루 루프

### 낮 — 모험가 창구 [확정]
- **시간 압박 있음** (영업 시간)
- 업무: **수주 심사** + **완료 심사**
- 처리량이 많을수록 수수료·호감도 증가. 상한은 게시판 퀘스트 수로 제한
- **실수 비용 > 속도 이득**이 되도록 밸런싱 [제안]
- 게시판을 다 비우고 시간이 남으면 네임드 잡담 등 여유 보상 [제안]
- 못 처리한 의뢰는 기한이 줄어든 채 이월 [제안]
- 긴급 의뢰 난입 이벤트 (가끔) [제안]
- 창구 잡담 중에도 타이머가 흐르게 할지 [미정]

### 밤 — 사무 [확정]
시간 압박 없음. 목표 3~5분. 검수가 아니라 **선택**의 시간.

1. 오늘 결과 정리
2. **의뢰서 작성** — 의뢰인이 낮에 두고 간 의뢰서를 읽고 길드 기입란 작성 (3장 참고)
3. **게시판 구성** — 상한 내에서 무엇을 올릴지 선택 (돈 / 위험도 감소 / 기한 임박)
4. 자금 사용 (편의 시설)
5. **승급 심사** — 레벨 확인
6. **개인 이벤트** — 하루의 마지막

- 사기 의뢰 판별 같은 검수는 밤 루틴에서 제외. 가끔 스토리 이벤트로만 등장
- 몬스터 없는 의뢰(채집·잡무·호위)를 섞어 부담 완화 [확정]
- 하루 의뢰서 3~5장 정도 [제안]
- ⚠️ 밤 작업량이 많아지는 문제는 **논의 진행 중** → 12장 "이어서 할 논의" 참고

## 3. 서류

### 3-1. 길드 카드 (모험가 제출)

| 항목 | 용도 | 해금 |
|---|---|---|
| 이름 | 수배서 대조 | 수배서와 함께 |
| 초상화 | 실제 얼굴 대조 (대리 수주 적발) | 신원 확인 해금 시 |
| 등급 | 수주 범위 확인. 테두리 색으로도 표시 (위조 시 불일치) | 1주차 |
| 직업 | 의뢰서 필수 역할 대조 | 1주차 |
| 길드 인장 | 규정집의 정식 인장과 대조 | 2주차 |
| 카드 번호 | 등급 코드 형식 확인 (예: 동=B) | 후반 |
| 발급 길드 | 축제 주 등 외부 모험가 대응용 임시 항목 | 이벤트 |

- **위조 카드** [확정]: 위조 카드는 실제보다 높은 등급을 적어 온다 → 못 잡으면 실력이 모자란 모험가를 내보내게 됨. 위조 단서는 항목별로 하나씩: 테두리 색 불일치 / 가짜 인장(모양 차이) / 초상화가 창구의 본인과 다름(남의 카드) / 카드 번호의 등급 코드 불일치
  - 프로토타입에서는 테스트용으로 **하루에 하나씩** 해금 (2일차 테두리 → 3일차 인장 → 4일차 초상화 → 5일차 번호). 본편 해금 시점은 위 표(주 단위)를 따르되 추후 조정 [제안]
  - 해금은 전날 밤 **공문**으로 예고, 규정집에 [신규] 표시
- **스킬·속성은 카드에 없음** → 창구의 **마법구로 측정**해야 확인 가능 (측정에 몇 초 소요 → 시간 압박 속 판단 요소)
- **레벨도 카드에 없음** → 승급 신청서에만 기재
- 파티는 별도 신청서 없이 **파티원 카드 전부 제출**

### 3-2. 의뢰서

**의뢰인 작성란**
- 제목 (코미디 담당)
- 의뢰인 (이름, 직업)
- **상황 설명** — 몬스터 생김새·울음·흔적·수량 단서. 의뢰인 성격에 따라 과장/축소
- 지역
- 기한
- 제시 보상

**길드 기입란 (밤에 플레이어가 작성)**
- **대상 몬스터** — 설명을 읽고 도감에서 찾아 기입
- **추정 수량** — 설명에서 판단
- **권장 등급** — 도감의 수량별 등급표를 보고 도장
- **필수 역할 / 필수 스킬** — 도감 항목을 보고 지정
- 소요 기간 (1일 / 원정 최대 3일)
- 게시 인장

- 밤 기입 항목은 **낮 해금과 거울처럼** 열림 (낮 직업 확인 해금 주 = 밤 역할 지정 해금 주, 낮 스킬 측정 해금 주 = 밤 스킬 지정 해금 주) [제안]
- 플레이어의 진짜 판단은 **"무슨 몬스터냐, 몇 마리냐"** 두 가지로 좁혀짐

### 3-3. 창구 비치 자료
- **몬스터 도감** — 그림, 이름, 약점/내성 속성, **수량별 권장 등급**, 필요 역할, 필요 스킬, **증거 부위** (예: 늑대 → 늑대 송곳니, 1마리당 1개)
  - 헷갈리는 몬스터 쌍 배치 (개구리/거대 두꺼비, 들개/늑대 등)
- **수배서 게시판** — 초상화, 이름·가명, 특징, 현상금. 사건 있는 주에만
- **규정집** — 공문으로 늘어나는 규칙 모음. 예외 규칙 포함

### 3-4. 기타
- **완료 보고서 + 증거물** — 몬스터 부위 / 채집물. 종류·수량 대조, 허위 보고 적발 (코미디 자리)
  - 판단 기준 [확정]: 증거물이 **게시본 기입란**의 대상 몬스터 증거 부위인가 + 개수가 기입한 수량 범위 안인가. 몬스터 없는 의뢰는 의뢰서의 확인 물품
  - 허위 보고 유형 [확정]: 비슷한 몬스터의 부위(들개 이빨을 늑대 송곳니라고), 수량 부족, 증거물 없음("잃어버렸어요"). 실패한 모험가 일부가 성공이라 우김
  - 정직한 실패 보고는 확인만 (수수료 없음)
  - 밤 기입이 틀렸어도 성공한 모험가는 **게시본대로** 증거를 가져온다 → 창구에선 정상으로 보이고, 오판은 밤 결과 화면에서 드러남 (9장 패널티)
- **승급 신청서** — 레벨, 실적. 밤 승급 심사용

## 4. 검수 항목과 해금 [확정]

- 고정 항목: **등급, 직업, 파티 인원·조합, 길드 인장(신원), 상성, 스킬, 수배서(징계), 카드 번호**
- 항목 수를 늘리기보다 **항목 간 조합과 예외 규칙, 딜레마 상황**으로 깊이를 만든다
- 후순위로 뺀 것: 준비물, 컨디션, 중복 수주, 관계(분쟁)

### 임시 규칙 (이벤트성, 붙었다 떨어짐)
동시에 최대 1~2개, 시작·해제를 확실히 공지. 지나간 규칙이 재발하는 이벤트도 가능.

- 수배 기간 (도적단 등)
- **전염병 주간** — 상태(기침, 안색) 확인 [확정: 상태 확인은 여기로]
- 축제 기간 — 외부 길드 카드 양식
- 전시 차출 — 특정 역할 외부 파견 금지
- 감찰관 방문 — 서명·인장 엄격 확인
- 변장한 마족 잠입 — 종족 확인
- 지역 봉쇄 [미정/보류]

## 5. 수주 방식 [확정]

- 모험가가 **자기 등급에 맞춰 퀘스트를 들고 옴** — 단, 가끔 틀리게 (욕심 많은 신입, 상성 무시 등) → 검수 재료
- **지명 수주**: 길드 홀 대기자에 한해 플레이어가 급한 퀘스트를 지정 가능
  - 원정 중·부상자는 지명 불가
  - 지명 시 **보상 협상** — 호감도 높으면 쉽게 수락, 낮으면 흥정·거절. 협상이 길면 다른 업무가 밀림
  - 지명한 건은 전적으로 플레이어 책임

---

## 6. 판정 [확정]

- 판정 요소: 검수에 쓰는 **모든 항목**
- 각 퀘스트에는 **숨겨진 정답**(실제 몬스터·수량 → 필요 등급·역할·스킬)이 있음
  - 낮 심사는 플레이어가 밤에 기입한 기준으로 진행
  - 결과 판정은 숨겨진 정답 기준 → 밤의 오판이 며칠 뒤 사고로 돌아오는 **나비 효과**

| 결과 | 조건 |
|---|---|
| 대성공 | 미스매치 없음 + 호감도 높은 모험가일 때 일정 확률 |
| 성공 | 빠짐없이 적절하게 배치 |
| 부상 성공 | 미스매치 1개 (해당 모험가 며칠 출근 불가) |
| 실패 | 미스매치 2개 |
| 사망 | 미스매치 3개 이상일 때 확률적으로 (3주차부터 개방) |

- 확률은 공개하지 않음 (결과는 놓친 개수로 결정)
- 원인은 모험가 귀환 후 **대화로** 전달
- 항목별 가중치(치명적 미스 = 2개 취급 등) [미정 — 추후 밸런싱]
- 부상 조건의 "컨디션" 요소는 상태 확인이 전염병 주간으로 빠졌으므로 정리 필요 [미정]

## 7. 등급 [확정]

- **동 → 은 → 금 → 플래티넘 → 다이아** + 히든 **흑금** (전 세계 5명)
- **분포**: 동·은 대부분, 금 몇 명, 플래티넘 1~2명(네임드 위주), 다이아는 가끔 방문
- **수주 범위**: 자기 등급 이하. **파티는 한 단계 위까지 허용**
- **승급**: 모험가가 신청해야만 올라감. 레벨이 기준 중 하나
  - 수주 심사에서는 등급만 확인, 레벨은 **밤 승급 심사 전용**
  - 신입 접수원이 흑금 제외 전 등급 승급 권한 보유
  - 기준 미달인데 올려주면 버거운 퀘스트를 들고 와서 사망 위험 상승
- **흑금 활용** [제안]: 로스터에 없음, 스토리 전용 / 흑금 카드 사칭 사건 / 마지막 주 조건부 지원

## 8. 모험가와 호감도

### 모험가 구성 [확정]
- **네임드 일부 + 랜덤 생성 나머지**
- 네임드: 캐릭터와 이벤트에 공을 들임. **죽을 수 있음**
- 랜덤: 성격·특성 태그 조합의 미니 이벤트로 애착 형성 [제안]
- 네임드는 전투력이 아니라 **서사**로 차별화 [제안]
- 톤: 네임드는 웃기게 등장 → 개인 이벤트로 무거운 사연 공개 [제안]

### 이벤트 구분 [확정]
- **메인 슬롯 이벤트** — 역할 슬롯으로 설계. 누가 죽어도 대체 인물이 슬롯을 이어받음 (대사·연출만 교체)
- **네임드 개인 이벤트** — 대체 없음. 죽으면 사라짐 (상실감 + 다회차 동기)

### 호감도 [확정]
- 증가: 적절한 퀘스트 배정, 제대로 된 보상, 성공 보너스
- 감소: 부적절한 배정(너무 쉬움 = 소폭, 너무 어려움 = 대폭), 오래 기다리게 함
- 그 외 큰 변화는 **개인 이벤트**에서
- 호감도 변화는 숫자보다 **반응 대사**로 먼저 전달 [제안]
- 활용: 습격 때 지원 인원, 지명 수락률, 대성공 확률
- 호감도 높은 모험가가 무리해서 사망 위험이 오르는 역효과 [제안]
- ~~길드 평판(별도 수치)은 두지 않음~~ → **길드 평판 도입** [확정] (9장 참고)

### 개인 이벤트 배치 [제안]
- **낮 (조각)**: 창구 잡담, 서류 속 흔적(편지·낙서·메모), 네임드 관련 의뢰, 규정 딜레마
- **밤 (본편)**: 호감도 조건 충족 시 차분한 대화 이벤트

## 9. 경제 [확정]

- **길드 운영 자금**
- 수입: **퀘스트 완료 시 수수료** (완료 심사 때 창구에서 수령). 실패 시 수수료 없음
  - 수수료는 보상 비율이 아니라 **1건당 15G 고정** [확정]
- **잘못된 의뢰 성공 패널티** [확정]: 밤 기입이 틀린 의뢰가 성공해서 완료 승인한 경우, 창구에서는 수수료를 받지만 **밤 결과 화면**에서 의뢰인 항의로 수수료 회수(−15G) + 평판 하락
  - 허위 보고를 승인한 경우도 같은 패널티
- **길드 평판** [확정]: 0~100, 시작 50. 밤 결과 화면에서 정산
  - 완료 승인 +1 (대성공 +2) / 의뢰 실패 −2 / 정상 보고 반려 −2 / 기한 초과 −3 / 규정 위반 승인 −3 / 패널티 −5 [제안: 수치]
  - 평판이 게임에 주는 영향 [미정] (예: 들어오는 의뢰 수, 보상액, 방문 모험가 수)
- 사용처:
  - **편의 시설** — 마법구, 위조 판별기 등. 판단을 대신하지 않고 수고만 줄이는 보조 도구로 설계 (예: 의심 부위 표시, 사용 시 시간 소모). 관련 규칙 해금 시점에 상점 등장 [제안]
  - **보상 협상** — 낮 지명 때만. 인상분은 길드 부담 (수수료가 고정이라 보상 인상으로 수수료가 늘지 않음)
  - **성공 보너스** — 성공한 퀘스트에만 지급, 호감도 상승
- 자금 수급은 **빡빡하게**
- 게시판 상한, 편의 시설 목록·가격 [미정]

## 10. 마을 위험도와 주말 습격 [확정]

- **위험도**: 매일 자연 상승 + 외부 요인(번식기, 스토리 사건). 퀘스트 성공으로 감소
  - 실패·기한 초과 퀘스트는 위험도 상승
  - 퀘스트 종류별 영향 차이 (마을 근처 토벌 = 큼, 먼 채집 = 작음) [제안]
- **습격은 매주 주말 반드시 발생**. 위험도는 **습격 규모**를 결정
- 판정 요소 [제안]: 위험도, 마을 대기 전력(원정·부상 제외), 호감도 높은 모험가의 지원 인원, 긴급 의뢰 처리
- 결과는 점검표가 아니라 **이야기로 서술** ("북문은 ○○ 파티가 버텼지만 동문엔 남은 사람이 없었다…") — 조건별 문장 조각 조합
- 실패 → 목숨 이벤트 → 재실패 시 배드 엔딩
- 결과 3단계(완벽 / 아슬아슬 / 실패)로 사전 경고 효과 [제안]
- **성공 보상**: 참여 모험가 호감도 상승

## 12. 남은 작업

### ▶ 이어서 할 논의: 밤 작업량 (중단된 지점)

**배경**: 밤에 플레이어가 의뢰서의 대상 몬스터·수량·권장 등급·필수 역할·필수 스킬을 직접 기입하기로 확정했음 (나비 효과를 위해). 그런데 이러면 밤도 바빠져서 피로도가 올라가는 문제가 생김.

**확정된 것**
- 권장 등급은 자동 산출이 아니라 **도감의 수량별 등급표**를 보고 플레이어가 도장
- 필수 역할·스킬도 도감을 보고 플레이어가 지정
- 보상 인상은 밤이 아니라 **낮 지명 협상**에서만
- 몬스터 없는 의뢰를 섞어 부담 완화

**제안됐지만 결정 안 된 해결책**
1. 도감 한 페이지에 수량별 등급·역할·스킬을 모두 기재 → 진짜 판단은 "몬스터 식별 + 수량 추정" 두 개로 좁히고 나머지는 빠른 도장 입력
2. 밤 기입 항목을 낮 검수 해금과 거울처럼 단계적으로 개방
3. 하루 의뢰서 3~5장으로 제한
4. 밤 전체 목표 시간 3~5분

**다음에 정할 것**: 위 해결책 채택 여부, 밤 한 장당 처리 시간 목표, 1주차 밤에 기입할 항목 범위

### 전체 남은 작업

1. **프로토타입** — 카드 한 장, 의뢰서 한 장, 규정 두세 줄로 창구 하루 굴려보기
   - 진행 중 (Unity `Assets/Scenes/Prototype.unity`): 5일, 밤 의뢰서 작성 → 낮 수주 심사(등급·역할·인원 + 위조 하루 하나씩 해금) + 완료 심사(증거물) → 밤 정산(수수료·패널티·평판)
   - 화면 구성은 갈바테인식 3단 (왼쪽 서류·규정집 / 가운데 모험가 / 오른쪽 길드 카드·게시판)
2. 5주 타임라인 상세 (메인 이벤트, 해금, 랜덤 이벤트 슬롯, 전염병 주간 위치)
3. 세계관과 최종 위협, 떡밥 배치
4. 네임드 명단 (인원, 등급·직업, 겉모습과 사연, 역할 슬롯, 길드장)
5. 완료 심사 / 승급 심사 상세
6. 경제 수치
7. 랜덤 이벤트 풀, 엔딩 목록
8. 판정 가중치
9. 창구 화면 구성 (서류 배치, 대조 방식, 드래그앤드롭)
10. 길드 평판의 게임 내 영향
